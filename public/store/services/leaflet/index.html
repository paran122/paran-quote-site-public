리플렛 편집·인쇄

프로그램·사업 소개를 펼치는 순서대로 읽기 쉽게 정리하는 리플렛 제작 서비스

2단·3단·병풍 접지 편집 디자인

국문부터 다국어 리플렛까지

리플렛은 맡기고, 행사 준비에 집중하세요

  • 원고만 보내주세요

    글과 사진만 주시면 깔끔하게 정리합니다.

  • 펼치면 바로 이해되는 리플렛

    표지에서 내지까지 자연스럽게 이어집니다.

  • 인쇄·접지까지 한곳에서

    행사장에 바로 쓸 수 있게 제작해서 배송해 드립니다.

작업 사례

행사가 돋보이는 리플렛 제작 사례

사례를 누르면 현장 사진과 제작물을 크게 볼 수 있습니다.

    제작과정

    인쇄·접지 완료
    01

    원고·접지 확인

    사용 목적과 원고량, 규격·접지 방식을 확인합니다.

    02

    면별 편집

    표지와 내지의 정보 순서를 구성하고 시안을 검토합니다.

    03

    교정·인쇄

    오탈자와 접는 순서를 확인한 승인본으로 제작합니다.

    의뢰 범위

    파일로 받을지, 인쇄물로 받을지만 고르세요

    디자인 파일만
    PDFAIPNG

    디자인만

    편집 디자인한 리플렛을 파일로 받습니다.

    • 원고를 면별로 편집
    • 접는 순서대로 구성
    • 인쇄용 파일로 전달

    77만 원~A4 2단 접지 · 시안 1개 · 수정 2회 · 크기에 따라 금액 변동

    이 구성 선택
    인쇄까지 한 번에

    디자인 + 인쇄

    디자인한 리플렛을 인쇄·접지해 받습니다.

    • 디자인만 구성 모두 포함
    • 크기·용지·접지 맞춤 제안
    • 인쇄·접지해서 전달

    95.1만 원~디자인만 77만 원 + 인쇄 17.7만 원 + 택배 4,000원 · A4 · 스노우 250g · 양면 컬러 · 단면 코팅 · 100부 · 택배 포함(퀵은 실비) · 100부 추가 +7.2만 원

    이 구성 선택

    크기·접지·수량은 견적에서 고르고, 용지는 요청사항에 적어 주세요. 원고 작성·번역·교열은 별도 협의합니다.

    제작 전 확인사항

    제작기간

    배포일을 알려주시면 편집·인쇄·접지 일정을 거꾸로 맞춥니다.

    원고와 이미지

    면별 글·사진·표와 일정표·지도·QR 주소를 모아 보내주세요.

    크기와 접지

    옵션 크기는 펼친 크기입니다. 완성 크기 조건이 있으면 알려주세요.

    최종 시안 확인

    인쇄 전 오탈자와 접는 순서를 확인해 주세요. 확정 후 바뀌면 일정·비용을 다시 확인합니다.

    의뢰 전, 궁금한 점

    서비스·범위

    리플렛 제작은 어떤 서비스인가요?

    행사 프로그램 안내, 기관·사업 소개, 기업 홍보 리플렛을 원고에 맞춰 편집 디자인하고 필요하면 인쇄·접지까지 맡는 서비스입니다.

    다국어 리플렛도 만들 수 있나요?

    네. 같은 구성으로 언어별 리플렛을 만든 사례가 있습니다. 번역 원고는 전달해 주시고, 번역 작업이 필요하면 별도로 협의합니다.

    원고 작성도 포함인가요?

    제공 원고 기준 편집입니다. 원고 기획·작성이나 교열이 필요하면 별도로 범위를 협의합니다.

    기간·비용

    리플렛 비용은 어떻게 정해지나요?

    이 페이지 견적 상자에서 크기와 인쇄 수량을 고르면 부가세 포함 견적 금액이 바로 계산됩니다. 퀵 배송비와 직접 입력한 사양만 담당자가 확인해 안내합니다.

    공공기관도 수의계약으로 맡길 수 있나요?

    파란컴퍼니는 여성기업 인증 기업이라 5천만 원 이하 수의계약이 가능하고, 계약에 필요한 서류를 준비해 드립니다.

    자료·수정·납품

    면수가 헷갈리면 어떻게 하나요?

    넣을 원고와 참고 형태를 보내주세요. 접지 방식과 펼친 크기를 함께 확인해 면 구성을 정리합니다.

    같은 행사 포스터와 디자인을 맞출 수 있나요?

    공통 로고·색상·이미지와 기준 시안을 공유해 주세요. 포스터·현수막과 같은 톤으로 맞출 수 있습니다.
